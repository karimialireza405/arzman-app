# Security

Please report vulnerabilities privately by email to alirezkarimi0021@gmail.com
instead of opening a public issue. Include what you found, how to reproduce it and
the version or commit.

The project has no user accounts, no payment data and no market-API secret. Things
that must never be committed: `.env*` files (except `.env.example`), Android
keystores, Apple certificates and provisioning profiles, Cloudflare or Expo tokens.
